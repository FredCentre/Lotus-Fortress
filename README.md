## Installation 

Download the latest version file and extract the main file (named "TF2-Localization-Vietnamese") into your TF2 custom folder in the following file path: "steam/steamapps/common/teamfortress2/tf/custom" Also make sure that TF2-Localization-Vietnamese is the only folder present in the custom folder.
